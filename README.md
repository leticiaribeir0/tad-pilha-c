# TAD Pilha em C

Implementação de uma pilha encadeada em C, desenvolvida para a disciplina de Estruturas de Dados.

## Funcionalidades
- Criar pilha
- Inserir elementos (push)
- Remover elementos (pop)
- Verificar se a pilha está vazia
- Esvaziar e liberar a pilha
- Verificar expressões com parênteses, colchetes e chaves

## Tecnologias
- C
- VS Code
- Git
